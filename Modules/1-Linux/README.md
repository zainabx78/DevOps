# Linux Learning Notes 🐧

My personal notes from learning Linux and the command line. I'm building these as I go, from courses, practice and hands-on challenges like OverTheWire and SadServers.

Each page covers a topic in plain English, with the commands I used, what they do, and what I learned along the way.

## Contents

1. [Linux Commands](<Linux commands.md>)- The core commands for working with files and folders, plus shells, the Linux file system, sudo, users and groups.
2. [File Permissions](<File permissions.md>) - How read, write and execute permissions work, how to change them with `chmod`, and how to change ownership with `chown` and `chgrp`.
3. [Environment Variables](<Environment variables.md>) - What environment variables are, how to set them temporarily or permanently, adding folders to `$PATH`, and creating aliases.
4. [Standard Streams](<Standard Streams.md>) - Standard input, output and error, redirecting output into files, and throwing away errors with `/dev/null`.
5. [Linux Processes](LinuxProcesses.md) - Viewing running processes, monitoring with `top`, running jobs in the background, and stopping processes with `kill`.
6. [OverTheWire Bandit](OverTheWire.md) - My walkthrough of the Bandit wargame levels, with the challenge, solution, explanation and what I learned from each one.
7. [SadServers](SadServers.md) - Real-world troubleshooting scenarios, like finding and killing a process and finding the most common IP address in a log file.
8. [Text Processing](<Text Processing.md>) - Searching, pulling out and changing text with `grep`, `awk` and `sed`, and chaining them together with pipes.

## Skills Covered

- Navigating and managing files and folders
- Searching and filtering with `find`, `grep`, `sort`, `uniq` and `awk`
- File permissions and ownership
- Users, groups and `sudo`
- Environment variables and shell configuration
- Redirecting output and errors
- Managing processes
- Working with compressed files and hexdumps
- Troubleshooting real server problems

## Why I'm Doing This

I'm learning Linux because it runs most of the servers and cloud systems in the world. Writing my notes up like this helps me understand things properly, and gives me something to look back on.

## Key Takeaways

- Commit small and often, with clear messages.
- Always `git pull` before you `git push`.
- Use `reset` or `amend` only on commits you haven't pushed yet.
- Use `revert` to undo commits that are already shared.
- Use `--force-with-lease` instead of `--force` if you must force push.
